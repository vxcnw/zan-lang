### 4.4 背包页详解（页 20）⭐

整页分 **上 / 下** 两段，中间一条分隔线。

**上段**：
| 区域 | 内容 |
|------|------|
| 左 | 人物立绘（约 235×300，站在**装备栏中间**）：左列 3 格（项链/手镯/戒指）+ 右列 3 格（勋章/宝石/腰带）+ 底部 6 格（靴子等） |
| 中 | **6×6 = 36 格物品栏**（格 42×42，深底金边，数量角标左上） |
| 中左竖排按钮 | `切换仓库` `入库(F)` `加锁` `使用(A)` `整理` `放入图鉴` `仓库3` `一键熔炼` `卖出(X)`（宽约 76，高 30） |

**下段**：顶部 6 个平铺 tab
```
取出 | 说明 | 天书 | 内功 | 宝石 | 技能
```
- **取出**（默认）：2 行 × 5 格 + 每格下方「取出」钮
- **天书**：2 行 × 5 格 + 每格「取出」钮；右侧属性面板 `攻击/+0%` `魔法/+0%` `道术/+0%` `防御/+0%` `魔防/+0%` `负重/0/0`
- **内功**：左：**内功人物立绘**（盘坐，紫光）；右：2 列 × 5 行 → `内功: 金钟罩` / `等级: 0` / `效果: +0%防御` / `战功: 2.0000` / `金币: 1000.0000` + `升级` 钮（第二列同构：`铁布衫`）
- **宝石**：2 列 × 4 行，每行 = **装备类型图标**（剑/甲/帽/鞋 与 项链/手镯/戒指/另） + **4 格锁位**（未镶嵌显示 🔒）
- **技能**：2 列 × 4 行 → 每项 = 技能图标 + `强化攻击(0)` + 进度条 `106/250` + `Lv.2` `TP:0` + `升级` 钮

**下段左侧**（固定，不随 tab 变）：
- 顶部 `法师(3)` 标签 + `创建` `创建` 两个钮（**这是多角色槽位**）
- **职业选择**：`战士`（剑）`法师`（法杖）`道士`（符）三个图标
- **性别选择**：`男` `女` 两个图标
- `创建英雄` `取消` 两个按钮

## 五、通用组件规格（复用于所有页面）

### 5.1 主区内容框
```css
position: relative;
background: #0b0e14 ~ #10141c;   /* 近黑，带轻微蓝 */
border: 1px solid #2a3348;
```

### 5.2 Tab
- 竖排：宽 **86**，高 30，间隔 2
- 横排（背包下段）：宽约 **76**，高 26
- 选中态：底色 `#1a3a5c`，**浅蓝描边**
- 文字：`#a8b8d0`，选中 `#ffffff`

### 5.3 数据表格
| 元素 | 颜色 |
|------|------|
| 表头行 | 底色 `#1b2740`，文字 `#7ab8ff` |
| 偶数行 | `#0d1524` |
| 奇数行 | `#111a2e` |
| 高亮行（自己） | `#4a1a3a` 紫红 |
| 行高 | **20** |
| 分页 | 右上或右下：`说明` `上一页` `1/5` `下一页` |

## 七、玩法规则要点（摘自 `说明.txt`）

> 影响界面结构的规则，写代码时必须遵守。

| 系统 | 关键规则（影响 UI） |
|------|--------------------|
| **技能** | 10 个突破丹 = 1 级；每转生送 1 次全技能免费突破 → 技能页需显示「免费突破次数」 |
| **天书** | 转生 +1 负重，上限 10；特效天书重量 4 → 天书页需显示「负重: n/10」 |
| **内功** | 消耗战功 + 金币，递增；巅峰前不建议 → 内功页显示当前消耗 |
| **宝石** | 幻境出一级、秘境出二级；合成有几率带天赋 → 宝石页 4 槽/件 |
| **幻境** | 每天签到重置层数；有挑战失败次数限制；1500 层后出周年庆号角 |
| **秘境** | 可挑战层数上限 = **人物等级 + 100**；巅峰可挑战 |
| **世界BOSS** | **挑战次数与 BOSS之家共享**（重要！两个页面共用一个计数器） |
| **BOSS之家** | 编号 1-5 前期装备 / 6-14 转生证明 / 15-23 龙珠 / 24-28 渡劫证明；**挑战次数与世界BOSS共享** |
| **押镖** | 每天签到重置 5 次；每次 100 秒；可被劫镖 |
| **沙巴克** | 车轮战 KOF；每周一次；需会长提交祖玛头像或 100W 物资申请 |
| **城池** | 每人最多占 1 个城；占领后 1 小时内不能打其他城；7 天内领取一次，超 7 天可被踢 |
| **传说塔** | 一层本服、其余跨服；每层 +5% 经验加成；塔顶失败方 10% 掉装备 |
| **祭坛** | 每消耗 1000 进度兑换 1 次幻境重置；排名每日签到奖励 500/400/300/200 进度 |
| **图谱** | 积分 = 转生次数（0转1分…巅峰11分）；不能提取 |
| **极品殿堂** | 每件 +5% 经验加成，上限 50%（10 件）；复制收 10% 手续费 |
| **五行** | 一转后可用五行碎片激活；终身会员提高倍率 |
| **师徒** | 拜师条件 ≤60 级，出师 80 级，师父需 2 转；活跃度 100% 时徒弟领取翻倍 |
| **爵位** | >3000元宝=乡绅，>15000金=豪杰，>30000金=县令，>50000金=大臣；前 19 名有专属爵位 |
| **称谓** | 属性**递加不叠加**（筑基1阶+1攻1魔，2阶共+1攻1魔1道） |
| **洗练** | 普通洗练消耗金币有降系数风险；特殊洗练消耗元宝不降系数 |
| **龙珠** | 吞噬灵石升级，上限 = 转生等级×10；大90%/中50%/小10% 成功率，每次 100 元宝 |
| **天赋转移** | 消耗 1000 + 装备等级×10 的巅峰矿石；项链转移幸运、靴子转移速度 |
| **传说培养** | 每次 100 颗传说矿石；单条上限 = 人物等级/5 |
| **神兵图鉴** | 属性 = 系数×基数/10；满系数 = 装备等级/5 |
