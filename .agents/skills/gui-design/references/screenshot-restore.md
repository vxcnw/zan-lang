# 截图还原布局与交互体验基线

适用：用户给一张现有程序/网页截图，要求"照这个做 / 严格还原布局 /
复刻这个界面"，或者要求"让界面体验好一点"但说不清具体改什么。
分工：`app-migration` skill 管**程序级**复刻（映射账本、行为语义对齐）；
本文件管**单屏界面级**——一张截图到可编译、可验收的布局。审美档位
（字号/间距/高度阶梯）在 SKILL.md 主干，这里只讲"怎么把截图变成结构"。

## 0. 四条铁律

1. **几何忠实**：区块划分、从属关系、对齐线、比例、密度必须与截图
   一致。用户说"严格还原"时，结构自由度为零。
2. **语义提升**：量到的像素换算成档位（4 的倍数间距、阶梯字号/高度、
   token 颜色），不逐像素照抄——但换算不得改变视觉结构。截图里同排
   同类的控件尺寸不一致（AI 生成稿常见），还原时**归一到等宽/同高**，
   这叫修正不是走样。
3. **颜色字体走主题 token**；只有用户点名"同款配色"才从截图抽精确
   色值，并在交付说明里列出色板出处。
4. **文案一字不改**：语言、大小写、标点、占位数据都照抄截图。

## 1. 测量转写（先量后写，禁止边看边猜）

1. **定设计尺寸**：截图像素 ÷ DPI 缩放 = 设计像素。默认 100%；截图里
   文字/控件明显偏大（标题栏 >40px、正文 >20px）时按 125%/150% 折算。
   后续一切数字用设计像素。
2. **从外到内切区块，一次一刀**：标题栏 → 侧栏/导航 → 内容边距 →
   头部行 → 区块序列 → 状态条。每块记 x/y/w/h。
3. **块内再切**：行结构、列结构、卡片网格（数列数、量列距）、按钮组。
4. **控件清单**：类型 / 文案 / 状态（主次、禁用、选中、危险）/ 对齐
   （数字列右对齐？标签左对齐？）。
5. **产出布局账本**——还原的唯一依据，交付时逐行对账：

   | 区块 | 截图测量(设计px) | 原语映射 | token 换算 |
   |---|---|---|---|
   | 侧栏 | 宽 248 | Dock(3) | Prefer(230,0)，语义取整 |
   | 头行 | 高 64，左标题右动作 | Flex.Between() | 高度按内容量 |
   | 指标行 | 4 张等宽卡，列距 16 | Grid.Of(4) | Gap(16) |
   | … | … | … | … |

## 2. 原语映射决策树

- 通栏横条（顶部工具区/底部状态条）→ `Dock(1)`/`Dock(2)` + `Prefer(0,h)`
- 通栏竖条（侧栏/导航）→ `Dock(3)`/`Dock(4)` + `Prefer(w,0)`
- 其余内容区 → `Dock(5)`，内部按截图结构选：
  - 纵向堆叠的区块 → `Panel.Column().Gap(档)`
  - 一行多物（不等宽、工具行）→ `Panel.Row()` / `Flex`；左右两端对齐
    （左标题右按钮）→ `Flex.Row().Between().AlignCenter()`
  - 等宽卡片行/指标行 → `Grid.Of(n)`（**n 从截图里数出来**）
  - 左列表右详情（1:1 或 1:2）→ `Panel.Row()` 两子 `Grow()`，不要用
    两个 `Dock(5)`（会互相叠）
  - 表单 → `FormBuilder` 或标签列固定宽的 `Panel.Row`
  - 可滚动内容 → `ScrollView`/`ScrollColumn`
  - 弹层/抽屉 → `OverlayPopup`/`Layer`
- 手摆 `mx/my` 坐标在还原里**永远不出现**——截图是像素的，但还原产物
  必须是结构的，这样窗口缩放才不散。

## 3. 写码纪律

- 区块顺序、从属、可见对齐线与账本一致；区块标题与内容左缘共线。
- 截图里按钮/卡片的高度、内边距不量入代码——走主题默认（同档），这是
  铁律 2 的"修正"。
- 占位数据照抄截图（"请求 0 · 输入 0"就写这个字符串），让对拍时图文
  可直接对照。

## 4. 验证闭环（缺一步都不算还原）

1. 编译通过；`ZAN_GUI_OVERLAP=1` 跑一遍，`gui-overlap` 命中必须 0
   （环境变量用法见 SKILL.md"排版原语纪律"节）。
2. 以账本的设计尺寸起窗，按 `testing-gui-screenshot` 规范（锚 PID、
   按窗口截）截图。
3. 与原图**并排 + 50% 叠加**对比：区块边界误差 ≤ 半档间距、对齐线不歪、
   比例关系保持、文案全同。
4. 有偏差 → 改账本对应行 → 重截。小步收口，不做大面积重写。

## 5. 交互体验基线（还原/新写收尾都过一遍）

布局对了只是及格；下面每条都是"用户用起来顺不顺"：

**反馈闭环**
- 每个提交动作都有下文：进行中有 Spin/loading 文案，成功有 Toast，
  失败有具体错误 + 重试，绝不静默。
- 长操作进行中按钮禁用（防重复提交），完成后恢复。

**防呆**
- 破坏性操作（删除/停止/覆盖）二次确认，确认按钮用 danger 类，
  不与常用按钮贴邻。
- 表单必填/格式错误就地标出（红字在字段下），不在提交时才总报错。

**键盘与焦点**
- 表单 Enter 提交；弹窗 Esc 关闭；Tab 顺序 = 视觉顺序。

**状态完整**
- 空态用 Empty + 一句引导（"暂无模型映射——到模型映射页添加"）；
  错误态给具体原因；禁用态给原因（tooltip）。

**信息排版**
- 主按钮唯一且在最右/最下；数字列右对齐；同类列表行高一致。
- 导航当前项有选中态，页标题与导航项同名；文案动词具体
  （"启动代理"不是"确定"），全程同名。

## 6. 实战示例：Model Router 截图 → 布局账本 → 结构代码

截图 1794×1198 物理，文字偏大 → 按 150% 折算，设计 ≈1196×798。
账本（节选）：

| 区块 | 测量(设计px) | 原语映射 | token 换算 |
|---|---|---|---|
| 侧栏（品牌+菜单+底部网关态） | 宽 ~248 | Dock(3) | Prefer(230,0)；内部 brand Dock(1)/menu Dock(5)/状态 Dock(2) |
| 头行：眉题+标题 左，刷新/更多 右 | 高 ~44 | Flex.Row().Between().AlignCenter() | 高度按内容 |
| 指标行：4 张等宽卡 | 列距 ~11 | Grid.Of(4) | Gap(12) |
| 双栏：实时路由 \| 快速控制 | ~1:1 | Panel.Row 两 Card Grow() | Gap(12) |
| 用量统计通栏卡 | 高 ~150 | Card 塞进内容列末行 | 高度按内容 |

（截图原稿的巨型刷新钮、被裁的"…"、宽窄不齐的指标卡是原生成 AI 手摆
的病，还原时按铁律 2 归一——结构位置不变，尺寸回档位。）

还原代码骨架（已验证：编译通过，1200×800 下 Arrange 重叠命中 0）：

```zan
Panel root = new Panel();
Panel side = Panel.Column();                       // 侧栏
side.Dock(3).Prefer(230, 0);
Panel brand = Panel.Column(); brand.Dock(1);       // 品牌:名+副题
Panel menu  = Panel.Column(); menu.Dock(5);        // 菜单项逐行 With
Panel gw    = Panel.Column(); gw.Dock(2);          // 底部网关状态
side.With(brand); side.With(menu); side.With(gw);
root.With(side);

Panel content = Panel.Column().Gap(12);            // 内容列
content.Dock(5).Pad(4);
Flex head = Flex.Row().Between().AlignCenter();    // 头行
head.With(左标题列).With(右侧按钮行);
content.With(head);
Grid metrics = Grid.Of(4).Gap(12);                 // 指标行:四张等宽卡
metrics.With(MetricCard("本地代理", "运行中"));     // …×4
content.With(metrics);
Panel mid = Panel.Row().Gap(12);                   // 双栏 1:1
mid.With(路由卡.Grow()).With(快速控制卡.Grow());
content.With(mid);
content.With(用量卡);                               // 通栏收尾
root.With(content);
```

验证产物：`_scratch/overlap_probe/router.zan`（编译 + Arrange 零重叠）；
截图对拍按第 4 节执行。
